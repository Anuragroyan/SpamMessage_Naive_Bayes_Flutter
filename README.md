📩 Spam Detector

Spam Detector is a Kotlin-based Android application that uses the Naive Bayes machine learning algorithm to analyze user-provided messages and classify them as spam or legitimate. The app demonstrates practical machine learning concepts such as text classification, probability-based prediction, and on-device inference without requiring a backend.

✨ Key Features

* 📩 Spam and legitimate message classification
* 🤖 Naive Bayes machine learning algorithm
* 📝 User-provided text analysis
* 📊 Probability-based prediction
* ⚡ Real-time classification results
* 📱 Native Android implementation
* 🔒 Offline processing without a backend
* 🧩 Text preprocessing and classification workflow

🏗️ Architecture & Workflow

The application accepts text input from the user and preprocesses the message before passing it to the Naive Bayes classifier. The model evaluates the probability of the message belonging to spam or legitimate categories and returns the predicted classification, which is displayed through the Android UI.

🛠️ Tech Stack

Kotlin • Android • Machine Learning • Naive Bayes • Text Classification • Probability-Based Prediction

🎯 Project Purpose

This project demonstrates how a traditional machine learning algorithm can be implemented in a native Android application for real-time text classification. It provides practical experience with text preprocessing, probability-based prediction, and integrating machine learning logic into an offline Android application.
